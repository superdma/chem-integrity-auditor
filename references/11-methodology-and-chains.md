# 11 — 审查顺序与异常网络

这是一页“先查什么、什么时候算强”的跨轨清单，供 agent 在 03/04/05 之间
排序时使用。检查顺序受公开的 Geng-style 科研诚信审查清单启发；下面的
例子、阈值和判定标准已改写为化学/材料/电化学场景，不替代各轨的详细
playbook。

## 1. 图像身份冲突（不是“看起来像”）

问的不是“两张图相似吗”，而是“**同一视觉身份是否被贴上了不同的实验标签**”。

- 同一条 XRD 曲线标成两种不同材料；
- 同一张 SEM 图标成不同样品/不同放大倍数；
- 同一组 Raman 噪声出现在两个“独立测量”的谱里；
- 同一张 EDX 谱的峰被裁掉/加上后当作不同组成；
- 同一张 CV 曲线族换个扫描速率标签重新出现。

判定要点：共享的必须是**本应独立**的东西（噪声、缺陷、颗粒边界、基线
纹理），而不是共享的物理相（同一 ZnO 的峰位、同一晶体的点阵）。共享
峰位是良性解释；共享噪声纹理不是。

## 2. 数据复制与“反向生成”

比“数值相同”更强的是“数值像是从结论倒推出来的”。

- 整列/多列完全重复，或长连续片段重复；
- 一列由另一列固定加/减/乘/除得到（`numeric_forensics` 的
  fixed_difference / fixed_ratio）；
- 收率 = 转化率 × 选择性 但三者小数位/有效数字系统性不匹配；
- 百分比先定，原始计数后凑；同一分母异常频繁出现；
- CHN Found 与 Calcd 的差值全部落在同一侧、同一小数位；
- NMR 积分总和恰好等于分子式 H 数，但单峰积分不是 0.5 的倍数；
- HRMS 的 M+1/M+2 强度与分子式天然丰度不符，却与“手工凑出的同位素
  模式”一致。

“反向生成”是 Level 2–3 线索：它能解释为什么数据在数学上自洽、在实验
上不自然。不要单独用一条固定比例就定 Level 4。

## 3. 末位数字与过度整齐

化学测量中，末位 0/5 过多、所有值都是整数、所有百分比都到小数点后两
位且末位相同，都是线索，不是判决。

- 仪器精度决定合理末位：天平 0.1 mg、电位 1 mV、温度 0.1 °C；
- 收率/转化率保留 1 位小数很常见，全部保留 2 位且末位 0/5 才可疑；
- 小样本（n < 30）的末位分布没有统计力，只能作为 Level 1；
- Benford 只适用于跨多个数量级、n 较大、非有界的数据；收率、百分比、
  pH、电位、循环次数通常**不适用**，应在报告中明确写“不适用”。

## 4. 数学、单位与量程

- 百分比与计数能否在合理舍入内互推；
- 面积归一是否为 100%，分母是否同一；
- 单位是否可实现（mA cm⁻² vs A g⁻¹、mAh g⁻¹ vs F g⁻¹）；
- Scherrer 晶粒尺寸与 XRD 峰宽是否自洽；
- 电量/容量/电流密度/时间是否满足 Q = I·t 的量级；
- 表格里的“总和”是否等于各行之和（允许舍入误差）。

这些检查的价值在于**便宜且可复现**；一条不成立就可以把该发现降级。

## 5. 分布与趋势模板化

- 多组曲线形状过于一致，像同一模板加偏移/缩放；
- 独立样品的噪声过于平滑或过于相似；
- 数据没有自然离群点，或离群点恰好落在“好看”的位置；
- CV/GCD 曲线族在不同扫描速率下形状完全不变（真实体系通常有畸变）；
- XRD 峰宽/背景在所有样品上完全相同。

先做良性解释：同一材料、同一仪器、同一批次、同一绘图模板都可能产生
相似形状。只有**本应独立的噪声/缺陷**也重合，才是强线索。

## 6. 领域常识

- 测量精度是否符合仪器与实验惯例；
- 产率、纯度、容量、循环稳定性是否在领域合理范围；
- 表征是否真的支持结论（XRD 非晶→“高结晶度”、SEM 团聚→“均匀分散”）；
- 缺少关键对照（空白、标准、重复、稳定性/浸出）。

## 7. 作者回应压力测试

对作者/论文给出的解释，逐条问：

1. 这个解释能覆盖**全部**异常，还是只覆盖一个局部？
2. 如果解释成立，是否会引入新的矛盾（例如“误插入”却同时改变了标签、
   峰位和噪声）？
3. 原始数据能否同时解释图像和数值两条线？
4. 舍入/归一化/仪器精度能否解释所有小数规律？
5. 同一解释是否也能解释其他独立样品？

真实失误通常有一个一致的解释；编造的解释往往需要不断打补丁。把每个
补丁变成一个新的检验点。

## 8. 异常网络（最强证据）

单条线索最多 Level 2；强结论来自**独立线的汇聚**。

| 组合 | 典型读法 | 最高级别 |
|---|---|---|
| 图像复用 + 标签/描述冲突 | 同一图被当作不同实验 | Level 3–4 |
| 重复数值 + 固定偏移/比例 | 表格由模板生成 | Level 2–3 |
| 末位集中 + 重复小数尾 + 不可能舍入 | 手工编数 | Level 2–3 |
| 百分比/计数反向生成 + 同一分母异常频繁 | 先定结果后凑数 | Level 3 |
| 谱图共享噪声 + 峰形/标签不一致 | 同源数据重绘图 | Level 3–4 |
| 上述任一条 + 作者解释只覆盖局部 | 解释失败 | 升一级 |
| 仅 ORB/哈希命中，无标签冲突 | 可能同相/同图合法复用 | Level 1–2 |

“独立”很重要：同一张图的 dHash、ORB、noise_corr 不是三条独立证据；
图像 + 数值 + 作者回应才是。

## 9. 报告语言

- 写“与通知原文一致”“高度疑似失实”“需原始数据裁定”，不写“造假”；
- 每条发现写清楚：位置、技术、观察、最强良性解释、压力测试结果、缺什么
  原始数据；
- 阴性结果写“未检出像素级复用”，不要写“证明未造假”；
- 不适用写“Benford 不适用（收率有界、n 小）”，不要留空。
